# Website Criteria
- All Pages is implemented and accessible among all other pages
- The design is responsive across devices such as desktop, tablet and mobile
- Text content is proofread for grammar, spelling and clarity
  
# Menu 
- Product details are loaded correctly from database
- Each item is displayed correctly in respect to it's category

# Ordering & Checkout
- Users can add/remove items from their order
- Order summary shows correct items, sizes and prices
- A confirmation message or receipt is displayed after a successful order

# Performance & Securtiy
- Protected pages and features require user authentication
- Pages performs efficiently with no major slowdowns or loading issues 

# Testing
- All unit tests pass.
- User flows are manually test and verified
- Tets cover 85% or more of all files

# Deployment
- Code is pushed with no failing builds or deployment errors to the main branch
- Branches that are no longer needed are deleted
- All relevant issues and pull requests are closed when completed

# Documentation
- Code and documentation are up to date and describe current functionality
- Setup, usage and deployment instructions are oulined for future improvments/maintenace
